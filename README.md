# 어디가요 (Eodiga)

**노년층을 위한 대중교통 길안내 안드로이드 앱**

공공데이터포털의 실시간 대중교통 데이터를 사용해, 어르신이 혼자서도
버스를 타고 목적지까지 갈 수 있도록 안내합니다.

> HTML 목업을 실사용 가능한 안드로이드 앱으로 구현한 것입니다.
> 목업([`docs/original-mockup.html`](docs/original-mockup.html))은 브라우저로 열면
> 화면 흐름을 눌러볼 수 있고, **안내 음성이 실제로 나옵니다.**
> 기기 없이 문안을 귀로 확인하는 용도로 계속 씁니다.

---

## 무엇이 달라졌나

목업은 버튼을 누르면 다음 화면으로 넘어가는 11개의 정적 화면이었습니다.
실제 제품이 되려면 아래가 필요했습니다.

| | 목업 | 실제 제품 |
|---|---|---|
| 데이터 | 하드코딩 ("7016번, 3분 뒤") | 공공데이터포털 실시간 조회 |
| 경로 | 고정된 예시 하나 | 위치 기반 탐색 + 진행 방향 검증 |
| 화면 전환 | 사람이 버튼으로 | 위치·차량 위치에 따라 자동 |
| 하차 알림 | `setTimeout(4000)` | 실시간 차량 순번 기반 |
| 화면이 꺼지면 | 안내 중단 | **포그라운드 서비스로 계속** |
| 길 잃음 | `alert()` | 보호자에게 위치 문자 + 전화 |
| 오류 | 없음 | 상황별 어르신 언어 안내 |

가장 중요한 차이는 **화면이 꺼져도 하차 알림이 울린다**는 점입니다.
어르신은 버스에 타면 휴대폰을 주머니에 넣습니다.

## 사용하는 공공데이터

| 데이터셋 | 제공기관 | 용도 |
|---|---|---|
| 버스정류소정보 | 국토교통부 (TAGO) | 주변 정류소, 경유 노선 |
| 버스도착정보 | 국토교통부 (TAGO) | 실시간 도착, 저상버스 여부 |
| 버스노선정보 | 국토교통부 (TAGO) | 경유 정류소 순번 (방향 검증) |
| 버스위치정보 | 국토교통부 (TAGO) | 실시간 차량 위치 → 하차 알림 |
| 전국 병·의원 찾기 | 국립중앙의료원 | 목적지 검색 |
| 단기예보 | 기상청 | 출발 전 날씨 경고 |
| 도로명주소 | 행정안전부 | 주소 검색 |

자세한 내용과 실제 응답에서 겪는 문제들은 [`docs/public-data-apis.md`](docs/public-data-apis.md) 참고.

## 시작하기

### 1. 인증키 발급

1. [공공데이터포털](https://www.data.go.kr) 회원가입
2. 위 표의 **1~6번 데이터셋 각각** "활용신청" (버스 관련은 자동 승인, 보통 즉시)
3. 마이페이지 → 오픈API → 인증키 발급 현황 → **일반 인증키(Decoding)** 복사
4. (선택) [주소기반산업지원서비스](https://business.juso.go.kr)에서 주소검색 승인키 발급

### 2. 설정

```bash
cp local.properties.example local.properties
```

`local.properties` 를 열어 채웁니다:

```properties
sdk.dir=/path/to/Android/sdk
PUBLIC_DATA_SERVICE_KEY=발급받은_디코딩_인증키
JUSO_CONFIRM_KEY=주소검색_승인키   # 선택
```

> `local.properties` 는 `.gitignore` 에 있어 커밋되지 않습니다.
> CI 에서는 같은 이름의 환경변수로도 읽습니다.

> ⚠️ **Encoding 키가 아니라 Decoding 키**를 넣으세요.
> 대부분의 `SERVICE_KEY_IS_NOT_REGISTERED_ERROR` 는 이 문제입니다.

### 3. 빌드

```bash
./gradlew assembleDebug        # APK 빌드
./gradlew installDebug         # 기기에 설치
./gradlew test                 # 단위 테스트
```

**요구사항**: JDK 17, Android SDK 35, minSdk 26 (Android 8.0)

> **PC 가 없다면** — 저장소 Actions 탭의 "디버그 APK 빌드" 를 실행하면
> GitHub 이 대신 빌드해 APK 를 Artifacts 로 올려줍니다. 폰에서 받아 설치할 수 있습니다.
> 인증키 등록부터 설치·권한 설정까지 [`docs/install.md`](docs/install.md) 에 정리해 두었습니다.

> **폰이 없다면** — PC 의 안드로이드 에뮬레이터에서 앱을 그대로 돌릴 수 있습니다.
> 이 앱은 위치가 움직여야 화면이 진행되므로 가짜 이동을 넣어 주어야 합니다.
> 에뮬레이터 준비부터 경로 재생까지 [`docs/desktop-testing.md`](docs/desktop-testing.md) 에 있습니다.
>
> ```bash
> bash tools/emulator_smoke.sh                       # 설치 → 실행 → 스크린샷
> python3 tools/make_demo_gpx.py --out demo.gpx      # 가짜 이동 경로
> ```

### 4. 첫 실행

1. 위치·알림 권한 허용
2. **설정 → 가족 추가** — 길을 잃었을 때 연락할 보호자
3. **설정 → 자주 가는 곳 추가** — 집, 병원 등

보호자가 대신 해주는 것을 전제로 설계되었습니다.

## 구조

```
app/src/main/java/kr/eodiga/wayfinder/
├── core/            Outcome, 실패 분류, 재시도
├── data/
│   ├── remote/      Retrofit API, 인증키 처리, TAGO 응답 정규화
│   ├── local/       Room (저장된 장소, 보호자)
│   └── repository/  TransitRepository, PlaceRepository, WeatherRepository
│                    Epsg5179 / KmaGrid (좌표계 변환)
├── domain/
│   ├── model/       Journey, JourneyLeg, GuidanceStage, BusStop …
│   └── planner/     RoutePlanner  ← 경로 탐색 알고리즘
├── service/
│   ├── JourneyController        ← 안내 상태 기계
│   ├── JourneyGuidanceService   ← 포그라운드 서비스
│   ├── VoiceGuide / Haptics
├── location/        위치, 행정구역 변환
├── guardian/        길 잃음 처리 (문자 + 전화)
└── ui/              Compose 화면, 접근성 테마
```

### 핵심 설계 결정 세 가지

**1. 경로 탐색을 직접 구현했습니다.**
공공데이터포털에는 환승 경로 API 가 없습니다. 정류소·노선·도착·위치
네 가지 원본 데이터를 조합해 `RoutePlanner` 가 경로를 만듭니다.
노선의 경유 순번으로 **진행 방향을 반드시 검증**합니다 —
반대 방향 정류장 안내는 이 앱에서 가장 치명적인 실패입니다.

**2. 하차 알림에 도착예정시간을 쓰지 않습니다.**
정체 구간에서 예정 시간은 크게 흔들립니다. 대신 실시간 차량의
**경유 순번**으로 남은 정거장을 셉니다. 시간은 틀려도 정거장 수는 정확합니다.

**3. "가장 빠른" 이 아니라 "가장 쉬운" 경로를 고릅니다.**
```
난이도 = 도보시간 × 1.6 + 버스시간 + 환승횟수 × 8분
```
30분 걸려도 환승 없는 경로가, 22분이지만 두 번 갈아타는 경로보다 낫습니다.

## 접근성

모든 UI 결정은 노화에 따른 신체·인지 변화에 근거합니다.
자세한 내용은 [`docs/accessibility.md`](docs/accessibility.md).

- 본문 최소 22sp, 주 버튼 34sp, 핵심 숫자 88sp
- 모든 색 조합 대비 7:1 이상 (WCAG AAA)
- 터치 타겟 최소 96dp (Material 권장의 2배)
- 탭 제스처만 사용 — 스와이프·롱프레스 없음
- TTS 0.85배속, 버스 번호는 자릿수로 ("칠공일육")
- 거리는 미터가 아니라 걸음 수로
- 진동 패턴 3종이 독립적으로 의미를 가짐
- 지도를 기본으로 보여주지 않음

## 알려진 한계

- **환승은 1회까지만** 탐색합니다. 2회 이상은 API 호출량이 급증하고,
  애초에 어르신에게 권할 경로가 아닙니다.
- **지하철 미지원.** 목업의 승강기 안내 화면은 아직 구현되지 않았습니다.
  필요한 데이터셋은 확인했으나 엔드포인트 명세를 검증하지 못해
  추측한 URL 을 넣지 않았습니다. [`docs/public-data-apis.md` §7](docs/public-data-apis.md) 참고.
- **버스 소요 시간은 정거장당 2분 추정치**입니다. 구간별 실주행 시간
  데이터가 공개되어 있지 않습니다.
- **실제 어르신 대상 사용성 테스트를 거치지 않았습니다.**
  수치는 공개 가이드라인에 근거하지만, 실사용 검증은 별도로 필요합니다.
- 개발계정 일일 트래픽은 API 당 10,000건입니다.
  캐시와 적응형 폴링으로 줄였지만, 운영 배포 전 상향 신청이 필요합니다.
